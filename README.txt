РАБОТА БАНДИТА
1. В config.php вставь токен от @BotFather и свой Telegram ID.
2. Залей index.php и config.php на PHP-хостинг.
3. Нужны PHP 8+, SQLite, cURL, HTTPS.
4. Открой https://ТВОЙ-ДОМЕН/index.php один раз.
5. Напиши боту /start.
Команды: /start /work /balance /top /help
Админ: /give ID сумма, /take ID сумма, /set ID сумма
bot.sqlite создаётся автоматически. Токен никому не показывай.
